## 📁 Projects Included

### 1. 🏀 Sports Community Platform
A real-time social platform for sports enthusiasts to create, discover, and join matches.

**Tech Stack:** MERN, Redux, Socket.IO, Cloudinary, Google Maps API  
**Features:**
- Real-time notifications using Socket.IO
- Geo-location-based match discovery
- Image upload via Cloudinary
- Secure role-based authentication
- Team collaboration using Git & GitHub

---

### 2. 🏥 Medical Appointment Booking System
Role-based application for Admins, Doctors, and Patients with real-time video consultation and notifications.

**Tech Stack:** MERN, Redux Toolkit, Socket.IO, Razorpay, Cloudinary  
**Features:**
- Real-time video conferencing (Doctor–Patient)
- Live notifications using Socket.IO
- OTP & Email verification
- Payment integration with Razorpay
- Cloudinary for secure uploads

---

### 3. 👶 E-commerce Platform for Baby Products
An intuitive shopping platform for baby care items with cart, wishlist, and discount coupon features.

**Tech Stack:** React, Redux, Node.js, MongoDB, Cloudinary  
**Features:**
- Product browsing and smart filtering
- Wishlist and coupon management
- Secure cart + checkout system
- Toast alerts and error handling
- Admin panel for product management
